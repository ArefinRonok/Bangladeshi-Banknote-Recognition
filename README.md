# Bangladeshi Banknote Recognition

A computer vision and machine learning project for recognizing Bangladeshi banknote denominations.

## Project Overview

This project explores a complete banknote recognition pipeline, starting from image preprocessing and banknote localisation to feature extraction, machine learning, deep learning, and model visualization.

## Techniques Used

* Non-Local Means Denoising
* Grayscale Conversion
* Gaussian Blur
* Canny Edge Detection
* Otsu Thresholding
* Contour Detection
* Banknote Localisation and Cropping
* HOG Feature Extraction
* Colour Histogram
* Support Vector Machine (SVM)
* Random Forest
* MobileNetV2
* Grad-CAM

## Dataset

The dataset used in this project is available on Kaggle:

[Bangladeshi Banknote Dataset](https://www.kaggle.com/datasets/rahnumatasnim1604103/bangladeshi-banknote-dataset)

The dataset is not included in this repository.

## Results

The project evaluates classical machine learning and deep learning approaches using accuracy, precision, recall, and F1-score.
